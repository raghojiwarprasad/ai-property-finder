# Design the complete first experience

Use after the preceding stage meets its exit criteria.

Read PRODUCT_DECISIONS, 02_END_TO_END_EXPERIENCE, 03_UX_AND_SCREEN_SPEC, 06_USE_CASES and the golden lessons. Produce the core screen flow with desktop and mobile states. Show one operations learner and one developer so personalisation changes the work, not only the name. Include a wrong answer and the resulting targeted support. End with the implemented requirement IDs, evidence from validation, known limitations and the next stage. Preserve the product decisions and current repository instructions.

# Audit the actual product before a pilot

Use after the preceding stage meets its exit criteria.

Read all R1 PRDs and 09_MEASUREMENT_AND_LAUNCH. Walk through the product with the supplied contrasting learner fixtures. Audit every requirement ID as pass, fail, unverified or outside this release. Test keyboard/mobile flows, provider outages, source grounding, hidden answer isolation, retention/deletion and data ownership. Report severe blockers first. Do not call the product complete while a critical learning or privacy path is a mock.

End with the implemented requirement IDs, evidence from validation, known limitations and the next stage. Preserve the product decisions and current repository instructions.
